### 🤖 AI Image Classifier — Real vs. AI-Generated
**Python · EfficientNetB3 · Keras · Grad-CAM · Flask · Hugging Face Spaces**

But accuracy alone isn't enough — I added **Grad-CAM explainability**, so you get heatmap overlays showing *exactly which pixels* drove the decision. Deployed live with thread-safe prediction locking and cold-start auto-download.
